# Първи хапки

Дневник за захранване на бебе по насоките на СЗО – [parvihapki.eu](https://parvihapki.eu).

- Приложението е в един файл: `parvi-hapki.html`
- Сайтът се изгражда с `node tools/build-site.js` в папка `parvi-hapki-site/` и се публикува в Netlify
- Тестове: `node tests/run.js`
- Локален преглед: `node tools/serve.js parvi-hapki-site`

Подробно описание на проекта, решенията и следващите стъпки – в [CLAUDE.md](CLAUDE.md).
